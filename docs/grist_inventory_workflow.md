# Grist Inventory Workflow

This repo uses one Grist document as the operational UI for workshop stock and per-project cut/shopping lists, with durable JSON snapshots in git.

## Ownership rules

- Each project's OpenSCAD model (`projects/<slug>/model/`) plus that project's `extraction.py` are the source of truth for its `cut_list`.
- `projects/<slug>/data/cut_list.json` is generated. Do not edit it manually.
- `projects/<slug>/data/shopping_list.json` is generated by `scripts/compute_shopping_list.py` (product links filled by `diy-shopping`).
- `shared/inventory/inventory.json` is the repo snapshot of the shared Grist `inventory` table (edited in Grist, then pulled).
- Grist `cut_list` / `shopping_list` rows carry `project_id`. Primary keys in Grist are `{project_id}__{local_id}`.

## Table sync directions

| Grist table          | Direction                      | Scope                                      |
| -------------------- | ------------------------------ | ------------------------------------------ |
| `cut_list`           | local → Grist                  | Per project (`--project`)                  |
| `cut_list.completed` | Grist → local (merged on push) | Per project                                |
| `shopping_list`      | local → Grist                  | Per project                                |
| `inventory`          | Grist → local                  | Shared (`shared/inventory/inventory.json`) |

## Inventory reservation

When computing the shopping list for project P, incomplete cut rows from every other project reserve stock first (same greedy kerf/offcut rules as shortfall). P's shortfall is computed against what remains. That prevents two projects from both planning to consume the same stick.

## Initial setup (one-time)

1. Create a Grist document; copy the doc ID and an API key.
2. Copy `.env.sample` to `.env` and set `GRIST_API_KEY` / `GRIST_DOC_ID`.
3. Bootstrap schema (also runs automatically on every sync):

```bash
python3 scripts/sync_grist_tables.py --bootstrap-schema
```

4. Seed a project:

```bash
python3 scripts/extract_cut_list.py --project bin-store
python3 scripts/sync_grist_tables.py --project bin-store
```

## Day-to-day

```bash
python3 scripts/extract_cut_list.py --project <slug>
python3 scripts/sync_grist_tables.py --project <slug>
python3 scripts/compute_shopping_list.py --project <slug>
```

Skills: **diy-sync**, **diy-shopping**.
